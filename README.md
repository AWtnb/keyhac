# README

[keyhac](https://github.com/crftwr/keyhac) customization.

Environment:

- OS: Windows
- [CorvusSKK](https://github.com/nathancorvussolis/corvusskk)
- JIS keyboard


This project uses [uv](https://docs.astral.sh/uv/).

To set up the development environment, run:

```
uv sync
```

To install, run:

```
uv run install.py
```
